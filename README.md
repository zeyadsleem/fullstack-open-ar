# Full Stack open — النسخة العربية

موقع عربي كامل لدورة **Full Stack open** من جامعة هلسنكي وHouston Inc.، مبني من
الصفر باستخدام **SvelteKit**، مع دعم كامل للعربية واتجاه RTL.

## ما يتضمنه الموقع

- **15 جزءاً و68 فصلاً** بالعربية، تشمل:
  - الأجزاء 0-5: المحتوى الأساسي الكامل (React، JavaScript، الخادم، MongoDB، الاختبار).
  - الأجزاء 6-14: محتوى دورات mooc.fi الخارجية (إدارة الحالة، إضافات React، GraphQL،
    TypeScript، React Native، CI/CD، الحاويات، قواعد البيانات العلائقية، Next.js)
    مترجماً ومستضافاً داخل الموقع نفسه.
- صفحات الموقع: الرئيسية، عن الدورة، الأسئلة الشائعة، الشركاء وقصص المطوّرين، التحدي،
  والبحث في المادة.
- دعم RTL كامل، سمات فاتحة وداكنة، فهرس محتويات لكل فصل، وتنقل بين الأجزاء والفصول.
- جميع الصور والرسوم منقولة محلياً داخل `static/`، والموقع يعمل دون اتصال بالإنترنت
  (عدا خطوط Google Fonts).

## المتطلبات

- Node.js 20 أو أحدث
- pnpm

## الأوامر

```bash
pnpm install        # تثبيت الاعتماديات
pnpm dev            # تشغيل بيئة التطوير
pnpm build          # توليد المحتوى ثم بناء الموقع في build/
pnpm preview        # معاينة نسخة الإنتاج
pnpm content        # إعادة توليد المحتوى فقط
```

## بنية المشروع

```
content/                 المحتوى العربي النهائي (Markdown) — مصدر الحقيقة
  0/1/2/.../14/          ملفات الأجزاء والفصول
  navigation.json        عناوين الأجزاء والفصول ومساراتها (slugs)
content-src/             المحتوى الإنجليزي المصدر
  repo/                  الأجزاء 0-5 من مستودع fullstack-hy2020
  en/                    الأجزاء 6-14 المحوّلة من دورات mooc.fi
sources/mooc/            استجابات API الخام لدورات mooc.fi
scripts/
  build-content.mjs      تحويل Markdown إلى JSON + فهرس بحث + manifest
  import-mooc.mjs        استيراد دورات mooc.fi وتحويلها إلى Markdown
  validate-content.mjs   التحقق من اكتمال المحتوى وسلامة بنيته
  check-english.mjs      كشف النصوص الإنجليزية المتبقية
src/
  routes/                صفحات SvelteKit (الرئيسية، الأجزاء، الفصول، الصفحات الثابتة)
  lib/                   المحتوى المولّد، نصوص الموقع، الأنماط
static/                  الصور والأصول الثابتة
TRANSLATION.md           دليل الترجمة والمصطلحات وقواعدها
```

## كيف يعمل توليد المحتوى

1. تُكتب ملفات Markdown العربية في `content/<part>/`.
2. يقرأ `scripts/build-content.mjs` الملفات، ويزيل ترميز Markdown، ويولّد HTML مع
   تلوين الشيفرة عبر highlight.js، ويضيف معرّفات للعناوين لبناء فهرس الفصل.
3. تُكتب النتيجة في `src/lib/generated/` (manifest + محتوى كل فصل + فهرس البحث).
4. تُبنى صفحات الموقع مسبقاً (prerender) إلى HTML ثابت في `build/`.

## تحديث المحتوى

- لتصحيح ترجمة أو تحديث نص: عدّل الملف في `content/` ثم نفّذ `pnpm build`.
- لتحديث مادة الأجزاء 6-14 من mooc.fi: حدّث `sources/mooc/*.json` عبر تشغيل
  `scripts/import-mooc.mjs` بعد إعادة جلب البيانات، ثم أعد ترجمة الملفات المتغيرة.
- لأي ترجمة جديدة التزم بـ`TRANSLATION.md`.

## النشر

الموقع ثابت بالكامل. بعد `pnpm build` يمكن نشر محتوى `build/` على أي استضافة
(GitHub Pages، Netlify، Cloudflare Pages...). ملف `.nojekyll` موجود لدعم GitHub Pages.
